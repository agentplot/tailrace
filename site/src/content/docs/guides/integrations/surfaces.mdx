A surface is where a person or a program asks tailrace a question. Every
surface answers from one core, and the same question on any surface gets
the same answer (56). No surface computes a verdict, a version or a
channel of its own.

## The contract

A surface is not a seam of Part B; it is bound by Part A's rules for
askers (56 to 60). Every answer is readable by a program on request, in
a form that names digests, versions, channels and verdicts as the
statement names them (57). tailrace never answers a refusal as an
absence, an absence as a refusal, or either as unknown; a refusal names
the first claim found wanting and why, and carries the underlying
store's, signer's or ecosystem's own words verbatim beside tailrace's
(58, 59). Asking what tailrace holds reaches no store, no signer and no
target, and writes nothing (60).

## What status shows

`tailrace status` answers in any checkout of a repository, on any
machine, one that never published included: a fresh clone on a host
with no bindings file is bound to the branch, or sluice where the
repository is set up for it, and the git ref ledger, and nothing is
written to bind it (118). It names the branch and the landed revision
its policy was read at, and then, for each channel the policy declares
(131), its component, the channel it is bound to where it is one, and
the version it is at or that it is empty (31). Below each version is
the chain of promotions that put it there, newest first: the version it
moved from, who asked, when, and the claim (33). The channels are read
from the ledger alone, so every machine asking one ledger is answered
one version per channel; a chain the ledger could only answer as this
host last fetched it says when, with the remote's own words (36, 61).

Beside the channels are two parts of their own. The environments are
answered unreadable, saying what each should run and runs is read from
a target and no target is read yet, never as none behind (98). What
this host published comes from its own record, absent on a machine that
never published (61). A chain that cannot be read, a fork the ledger
refuses and a channel never promoted are three answers, each carrying
the ledger's own words, and one channel's answer leaves every other
shown (58, 59). `tailrace status --json` prints the same answer as one
document, and asking writes nothing and reaches no store, signer or
target (60).

## Adding one

A surface calls the one core and renders its answer; it reads no store
itself and derives nothing from a tag listing. A surface in the
repository is a moon project of its own, held to the same gate as the
rest; the conformance suite holds the core it calls (93).
