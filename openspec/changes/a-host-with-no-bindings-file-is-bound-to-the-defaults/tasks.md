unit comes after the-publishs-host-tells-the-gate, status-on-any-machine
and the-channels-answer-says-how-each-moves, and builds on their code
as their branches hold it. Before group 4, take in
`unit/the-channels-answer-says-how-each-moves` as it now stands, or the

`profiles/policy/file/` with its tests and `givens.toml`,

plugin directory: its tests run in the existing projects' `test` tasks
