# Tasks

Every cargo and moon command runs as `devenv shell -- <command>`. This
unit comes after the-publishs-host-tells-the-gate and builds on its code
as the branch holds it: its `Teller`, `Teller::of` and publish's telling
of the gate; where any of it is missing from the branch, report it with
`crew needs`. Before starting, read
`crates/tailrace/src/bindings/mod.rs` and its tests, the four families'
`mod.rs` under `crates/tailrace/src/profiles/{store,landing,ledger,signer}/`,
`profiles/signer/host_key/` with `listed.rs`, `profiles/run.rs`,
`crates/tailrace-core/src/gate.rs` with its tests and the conformance
suite's gate group, `tests/laptop.rs`, `tests/one_host.rs` and
`tests/publish_tells_the_gate.rs` with `tests/scratch/`, and ADR 0013.
No seam trait, shared type, fake or core module other than `gate.rs`
changes; a need for one is reported with `crew needs`. The change adds
no crate, language, file type or plugin directory: its tests run in the
existing projects' `test` tasks (the fast layer) and the `cli`
project's `tools` task (the tools layer, which already runs `--test
laptop` and `--test one_host`). Outside `crates/tailrace/src/profiles/`,
no file this change writes holds a word core.1 rules out.
