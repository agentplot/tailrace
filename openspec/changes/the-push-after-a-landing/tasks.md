# Tasks

Every cargo and moon command runs as `devenv shell -- <command>`. Code
starts once `moons-cache-namespace` has merged into the bolt and this
worktree is rebased onto it: the push codes against its `cache::write`,
`cache::Written`, `cache::sync`, the moon cache projection, the bound
projections taking the store and the checkout, `For::Sync`,
`FakeStore::forget` and the cache group's helpers. Read
`crates/tailrace-core/src/cache.rs`, `published.rs`, `publish.rs`,
`landed.rs` and `history.rs`, `crates/tailrace/src/commands/sync.rs`
and `publish.rs`, `bindings/mod.rs`, `render.rs`,
`crates/tailrace-conformance/src/core/cache.rs`, `core/status.rs` and
`world.rs`, and `crates/tailrace/tests/scratch/` and `laptop.rs` before
starting. The change adds no crate, language, file type or dependency,
so no moon project or formatter entry; its tests run in the existing
`core`, `conformance` and `cli` projects' `test` tasks and in
`cli:tools`.
